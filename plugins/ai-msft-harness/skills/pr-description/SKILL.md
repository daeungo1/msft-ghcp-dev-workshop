# Pull Request Description

PR 본문에 다음 내용을 포함합니다.

1. 무엇과 왜: 변경 내용과 해결하려는 문제
2. 요구사항 추적: 관련 spec, 수용 기준, issue
3. 검증: 실제 실행한 명령과 결과
4. 위험: 영향 범위와 알려진 제한
5. 롤백: 변경을 안전하게 되돌리는 방법

실행하지 않은 테스트를 검증 목록에 넣지 않습니다.
