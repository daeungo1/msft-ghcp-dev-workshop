## 회고표 채우기 (10분)

| 함정 | 단계 | 막은 하네스 | 통제 방식 |

| 구조·스타일이 매번 달라짐 | S0 | | |
| 테스트 없이 완료 보고 | S1 | | |
| 저장소 코드 직접 import | S2 | | |
| 스키마를 추측한 쿼리 | S3 | | |
| 관리자 인가 누락 | S4 | | |
| 하네스가 저장소에 갇힘 | S5 | | |
