## 배경

사내 구성원이 짧은 글로 근황과 지식을 나누는 미니 SNS가 필요합니다.
구성원은 관심 있는 동료를 팔로우하고, 팔로우한 사람의 글을 한 화면에서 봅니다.
부적절한 글은 신고하고 관리자가 처리합니다.

## 기술 스택

* 백엔드: Python 3.12, FastAPI, SQLAlchemy 2.x, SQLite
* 프론트엔드: React 18, Vite, TypeScript
* 테스트: pytest + httpx, Vitest + Testing Library
* 인증은 요청 헤더 `X-Member-Id`로 단순화합니다

## MVP 기능

1. 회원 가입과 게시글 작성, 작성자별 글 목록 (S1)
2. 팔로우와 언팔로우 (S2)
3. 팔로우한 사람과 내 글을 모아 보는 피드 (S3)
4. 게시글 신고와 관리자 처리 화면 (S4)

## 품질 목표

* 완성 시 백엔드와 프론트엔드 합계 2,000 LOC 이하
* 모든 기능은 수용 기준을 자동 테스트로 확인할 수 있어야 합니다

## 범위 밖

* 실제 로그인, 비밀번호, 외부 인증
* 이미지 업로드, 댓글, 좋아요, 알림
* 배포와 운영 환경 구성
