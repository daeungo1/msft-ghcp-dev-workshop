## 배경

구성원은 팔로우한 사람과 자신의 글을 한 화면에서 최신순으로 봅니다.

## 기능 요건

1. `GET /api/feed?limit=20&before=`: 팔로우한 사람의 글과 본인 글을 최신순으로 반환합니다.
2. `before` 커서로 다음 페이지를 조회합니다.
3. 숨김 처리된 글은 피드에 나타나지 않습니다.
4. 화면: 피드 목록을 S1 글 목록 자리에 연결합니다.

## 수용 기준

* Given A가 B를 팔로우할 때 / When A가 피드를 조회하면 / Then A와 B의 글만 최신순으로 반환합니다
* Given 글이 25개일 때 / When `limit=20`으로 조회한 뒤 마지막 글을 `before`로 다시 조회하면 / Then 나머지 5개를 반환합니다
* Given 숨김 처리된 글이 있을 때 / When 피드를 조회하면 / Then 그 글은 제외됩니다
