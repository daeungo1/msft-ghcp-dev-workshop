## 배경

구성원은 이름으로 가입하고 짧은 글을 남깁니다.
화면에서는 회원을 골라 그 회원으로 글을 쓰고 목록을 봅니다.

## 기능 요건

1. `POST /api/members`: 이름으로 가입합니다. 이름은 1~30자입니다.
2. `GET /api/members`: 회원 목록을 조회합니다.
3. `POST /api/posts`: 인증된 회원이 1~280자 글을 작성합니다.
4. `GET /api/posts?author_id=`: 작성자별 글 목록을 최신순으로 조회합니다.
5. 화면: 상단 회원 선택 드롭다운, 글쓰기 폼, 글 목록을 둡니다.

## 수용 기준

* Given 같은 이름의 회원이 없을 때 / When 이름으로 가입하면 / Then 201과 회원 정보를 반환합니다
* Given 같은 이름의 회원이 있을 때 / When 같은 이름으로 가입하면 / Then 409를 반환합니다
* Given `X-Member-Id` 헤더가 없을 때 / When 글을 작성하면 / Then 401을 반환합니다
* Given 281자 글일 때 / When 글을 작성하면 / Then 422를 반환합니다
* Given 한 회원이 글 3개를 썼을 때 / When 작성자별 목록을 조회하면 / Then 최신 글부터 3개를 반환합니다
