## 배경

S0~S4에서 만든 하네스는 이 저장소 안에만 있습니다.
다음 프로젝트에서도 같은 BP가 동작하도록 팀 플러그인으로 묶고, 우리 팀 규칙 하나를 더합니다.

## 기능 요건

1. `plugins/teamfeed-harness/`에 스킬, 커스텀 에이전트, 훅, MCP 설정을 플러그인 구조로 옮깁니다.
2. 다른 저장소(`sandbox`)에서 플러그인을 설치해 로드되는지 확인합니다.
3. `templates/team-rule-template.md`로 내 팀 규칙 1개를 스킬 또는 훅으로 작성해 플러그인에 추가합니다.
4. 플러그인 버전을 0.2.0으로 올립니다.

## 수용 기준

* Given 플러그인을 만들었을 때 / When `plugin.json`을 검사하면 / Then 유효한 JSON이고 필수 필드가 있습니다
* Given 플러그인을 설치했을 때 / When 다른 저장소에서 스킬 목록을 보면 / Then `tdd`와 내 팀 규칙이 보입니다
* Given 팀 규칙을 추가했을 때 / When 버전을 확인하면 / Then 0.1.0이 아닙니다
