# TeamFeed Workshop v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preserve TeamFeed v0.1 and rebuild `main` as a Spec Kit 1.2.5
multi-agent, multi-harness workshop.

**Architecture:** Keep the completed TeamFeed application as the stable exercise
domain. Replace the workshop control plane with the official Copilot Spec Kit
integration, model-neutral role agents, layered guardrails, a resumable workflow,
and a distributable bundle source.

**Tech Stack:** Spec Kit 1.2.5, GitHub Copilot customizations, Bash, Python 3.12,
FastAPI, SQLAlchemy, React 18, TypeScript, Vitest, GitHub Actions

**Spec:** `docs/superpowers/specs/2026-11-02-teamfeed-v0-2-design.md`

## Global Constraints

* Preserve existing `s0-done` through `s5-done` history.
* Create `main-v0.1` from the completed `final` commit.
* Do not push or rewrite remote history.
* Pin generated Spec Kit project files to `v1.2.5`.
* Keep model names out of required agent and workflow contracts.
* Keep the SQLite MCP integration read-only.
* Preserve TeamFeed API behavior and package boundaries.

## Review Focus

* Existing modified Spec Kit-managed files must not be silently overwritten.
* A missing optional model must not block the default workflow.
* Local workflow and bundle sources must resolve without network access.
* Hook failures must report the failed gate instead of returning success.
* Existing application tests must remain unchanged and pass.
