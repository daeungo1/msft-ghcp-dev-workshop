# 명세: TeamFeed MVP

## 사용자와 목표

팀 구성원이 짧은 글(최대 280자)을 올리고, 팔로우한 사람의 글을 한곳에서 보며, 부적절한 글은 신고합니다. 관리자는 신고를 검토합니다.

## 사용자 스토리

| ID | 스토리 | 단계 |
|---|---|---|
| US1 | 구성원은 이름으로 가입하고 글을 쓸 수 있다 | S1 |
| US2 | 구성원은 다른 구성원을 팔로우하고 해제할 수 있다 | S2 |
| US3 | 구성원은 팔로우한 사람과 자신의 글을 최신순 피드로 본다 | S3 |
| US4 | 구성원은 글을 신고하고, 관리자는 신고를 검색하고 처리한다 | S4 |

## 수용 기준

### US1 회원과 게시글

* 같은 이름의 회원이 있으면 409를 반환합니다.
* `X-Member-Id` 헤더가 없으면 글 작성은 401을 반환합니다.
* 281자 글은 422를 반환합니다.

### US2 팔로우

* 자기 자신을 팔로우하면 422를 반환합니다.
* 이미 팔로우 중이면 409를 반환합니다.
* 존재하지 않는 회원은 404를 반환합니다.

### US3 피드

* 팔로우한 회원과 본인의 글만 최신순으로 반환합니다.
* `limit`와 `before`로 페이지를 나눕니다.
* 숨김 처리된 글은 포함하지 않습니다.

### US4 신고

* 같은 회원이 같은 글을 두 번 신고하면 409를 반환합니다.
* 신고 목록 조회와 처리는 관리자만 할 수 있고 일반 회원은 403을 받습니다.
* 신고 검색 키워드는 SQL에 바인딩 파라미터로만 전달합니다.

## 범위 밖

* 글 수정과 삭제, 이미지 첨부, 알림, 실시간 갱신
* 로그인과 비밀번호 (요청 헤더 `X-Member-Id`로 대신합니다)
