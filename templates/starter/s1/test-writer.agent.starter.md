이 파일은 스타터입니다. TODO를 지우고 채우세요.

## 역할

TODO 이 에이전트가 맡는 일과 맡지 않는 일을 구분해 적습니다.

## 작업 순서

1. TODO 입력으로 읽을 문서 (힌트: requirements/ 의 수용 기준)
2. TODO 만들 산출물 (힌트: backend/tests/<패키지>/ 아래 테스트 파일)
3. TODO 실패를 확인하는 명령
4. TODO 끝났을 때 보고할 것

## 하지 않는 일

* TODO 쓰기 금지 경로 (힌트: backend/app/ 아래 구현 코드)
