이 파일은 스타터입니다. TODO를 지우고 채우세요.

## 역할

TODO 이 에이전트가 맡는 일과 맡지 않는 일을 구분해 적습니다.

## 작업 순서

1. TODO 시작 전 확인할 것 (힌트: 실패하는 테스트가 먼저 커밋되어 있는가)
2. TODO 구현 범위 (힌트: 테스트를 통과시키는 데 필요한 최소한)
3. TODO 끝났을 때 실행할 명령과 보고할 것

## 하지 않는 일

* TODO 테스트 파일에 대한 규칙 (힌트: 실패한 테스트를 고치지 않고 구현을 고친다)
* TODO 범위 밖 수정에 대한 규칙
