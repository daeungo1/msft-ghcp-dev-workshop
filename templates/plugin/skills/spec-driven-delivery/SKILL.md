# Spec-Driven Application Delivery

1. Establish project principles in the constitution.
2. Specify user scenarios, acceptance criteria, and non-goals.
3. Clarify decisions that would change the implementation.
4. Apply team-application-standards to runtime lifecycle, Clean Architecture
   boundaries, migration seams, data contracts, and verification.
5. Decompose work into failing tests, minimal implementation, and review.
6. Implement one module/service or one use case with TDD and run the complete
   quality gates.
7. Compare the current code with the specification and repeat until converged.
8. Extract reusable team procedures into plugin assets.
